# LAN Chat (局域网即时通讯与私有文件网盘)

**中文说明文档** | [English](README_EN.md)

> **作者**: [@EI3247](https://github.com/EI3247)  
> **开源地址**: [https://github.com/EI3247/lan-chat](https://github.com/EI3247/lan-chat)  
> **开源协议**: [MIT License](LICENSE)

专为局域网环境设计的轻量级即时通讯、私人网盘与 WebRTC P2P 大文件直传系统。  
后端采用 **FastAPI + SQLite** 单文件架构，前端使用 **原生 HTML5 / CSS3 / JavaScript** 构建，无额外 Node.js 编译构建链。支持单 Docker 容器一键交付，也支持宿主机免容器直接运行。适用于家庭 NAS、工作室、小团队及实验室内部协同。

> 💡 **访问优化建议**：若配合路由器 DNS 重写（如 AdGuard Home / OpenWrt / dnsmasq）将局域网 IP 映射为自定义短域名（如 `http://chat.lan:1111` 或 `http://l.com:1111`），局域网内所有手机、电脑、平板打开浏览器即可直达，无需记忆动态 IP。

## ✨ 核心能力与功能实现

### 1. 账号体系与身份码机制 (`id_code`)
* **零门槛即开即用**：首次访问只需填写昵称并选择头像，无需复杂的账号密码注册。
* **唯一身份码生成**：首次进入系统自动分配一个 6 位唯一随机身份码。用户可在个人设置页随时将其修改为自定义身份码（支持中文字符与英文字符）。
* **个人密码加固**：身份码默认作为唯一凭据；用户亦可选择性设置个人密码增加私密性。
* **跨设备与跨浏览器身份恢复**：更换设备、切换浏览器或清除浏览器缓存后，在登录页输入「身份码（+密码）」，即可立即继承原账号所有数据（头像、私人消息、个人文件）。
* **无感数据合并**：若在恢复原身份前已在临时会话中发送过消息或文件，在完成身份绑定时系统会自动将当前临时数据完整合并挂载至目标账户下，避免数据丢失。

### 2. 即时通讯系统
* **高并发实时通讯**：基于 WebSocket 连接池实现全双工消息广播与定向推送，支持文字、表情、图片、音视频与任意格式文件附件。
* **消息生命周期控制**：
  * **在线编辑**：消息发出后支持二次编辑修改。
  * **撤回与恢复**：用户可撤回自身消息，亦可主动恢复撤回内容；管理员在后台具备全量消息还原与审计能力。
  * **可见性动态切换**：支持将群聊消息一键设为私人可见（或反向公开），切换后消息自动刷新时间戳并重新置顶于时间线。
* **长文本与排版自适应**：超长文本消息自动折叠并提供渐变展开交互；输入框（Composer）采用悬浮胶囊设计，支持随内容实时自适应撑开高度（限制最大屏高，避免遮挡视口）。
* **用户资料与在线状态检测**：点击头像呼出名片面板，展示加入时间、活跃记录、来源 IP 及历史发言，并具备实时在线状态探测。

### 3. WebRTC P2P 大文件高速直传
* **点对点直连传输**：两台局域网设备间直接建立 WebRTC 数据通道（RTCDataChannel），数据流全程仅在客户端之间传输，**不经过服务端中转、不消耗服务器存储空间与网络带宽**。
* **单连接多文件队列**：支持批量勾选多个文件一次性发送。接收端仅需点击一次确认，系统自动复用同一条数据通道按队列分片传输所有文件。
* **传输控制与流量调节**：支持单文件最大 5GB，采用 64KB 分片机制与动态流量控制（缓冲区监控），两端实时同步文件索引与进度百分比，支持在等待确认及传输阶段随时单方取消。
* **局域网连接约束**：当前默认采用无 STUN/TURN 的纯内网直连架构，适用于同一局域网拓扑；若经由公网穿透访问，P2P 通道可能受限于 NAT 穿透而退回普通上传。

### 4. 双模式网盘与 Quick Drop 快捷投递
* **公私双模式网盘 (`/files`)**：
  * **公开网盘**：集中呈现聊天室中所有公开共享的历史文件。
  * **私人网盘**：切换私人视角，专属管理与查看用户标记为私人的文件。
  * **「我的上传」独立过滤**：支持按当前登录用户精准筛选所有上传记录。
  * **文件管理交互**：支持快捷设为私人/公开、撤回文件、下载与链接复制。
  * **纯文本在线编辑**：支持文本格式文件在线免解压读取预览，所有者支持直接在线编辑并保存更新。
* **Quick Drop（免入库目录投递）**：
  * 面向 NAS 用户设计的免上传通道：直接将任意文件拷贝或移动至宿主机 `./data/quick_drop/` 文件夹中。
  * 网盘页面在请求时**实时扫描目录动态呈现**，无需通过浏览器上传，不写入 SQLite 数据库，文件标注为「快捷分享」。
* **响应式瀑布流布局**：
  * 网盘采用多列自适应瀑布流布局，移动端保持 2 列紧凑排布，宽屏 PC 自动扩展至 5 列。
  * 图片与视频自动生成缩略图，并对列表底部遮罩进行了精细化透视调优，保证滚动到底部时卡片文字清晰可读。

### 5. 隐蔽管理入口与后台运维 (`/admin`)
* **暗号式后台登录**：前端界面完全隐藏管理后台入口与按钮。管理员只需在**主聊天输入框内输入「超级管理密码」并直接发送**，系统自动完成鉴权并无缝跳转至 `/admin` 管理控制台。
* **全量数据审计与管理**：
  * **用户管理**：服务端分页检索全部用户基础信息、来源 IP 及最近活动时间。
  * **消息审计**：全量检索历史消息，支持强制编辑、物理删除与撤回恢复。
  * **文件管理**：集中管理存储文件，支持缩略图预览、强制删除与类型筛选。
  * **配置热更新**：动态配置站点标题、欢迎提示语、普通访问密码、超级管理密码及上传文件大小上限（MB，输入 0 为不限制）。
  * **系统运行时信息**：以 Tab 形式集成版本与运行环境数据（Python 版本、运行时主机名、真实数据路径等）。

### 6. 全端适配与轻量 WebView 兼容
* 深度适配桌面端、平板与移动端各种尺寸屏幕。
* **轻量内核兼容方案**：针对安卓低版本内核、X 浏览器及各类 App 内置 WebView 做了多层兼容保障：
  * 对不支持 HTML5 原生 `<dialog>` 的环境提供自动 CSS / JS 模态层降级。
  * 全量移除可选链操作符等现代 ES 语法，采用兼容语法避免解析中断。
  * 针对部分 WebView 在 WebSocket 连接时不携带 Cookie 的情况，内置 `/api/ws-token` 鉴权补偿机制。

## 🚀 快速启动与部署方式

本项目提供两种部署方式：**Docker 容器部署（推荐）** 与 **宿主机原生直接运行（免 Docker）**。

### 方式一：使用 Docker Compose（推荐，容器隔离）

```bash
docker compose up -d
```
默认配置下服务将运行在 `http://你的局域网IP:1111`。

#### `docker-compose.yml` 配置说明
```yaml
services:
  lan-chat:
    build: ./app
    container_name: lan-chat
    restart: unless-stopped
    ports:
      - "1111:1111"
    command: ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "1111", "--proxy-headers", "--forwarded-allow-ips", "*"]
    environment:
      # 访问密码：首次进入聊天室时使用（留空则免密）
      LANCHAT_ACCESS_PASSWORD: "change_this_access_password"
      # 后台管理密码：访问 /admin 时使用（留空则免密）
      LANCHAT_ADMIN_PASSWORD: "change_this_admin_password"
      # 会话签名密钥（生产环境建议修改为随机字符串）
      LANCHAT_SECRET_KEY: "change-this-secret-lan-chat-key"
      LANCHAT_DATA_DIR: "/data"
      LANCHAT_SITE_TITLE: "LAN Chat"
      LANCHAT_WELCOME: "局域网聊天室"
    volumes:
      - ./data:/data
```

---

### 方式二：宿主机原生运行（免 Docker，支持真实局域网 IP 审计）

适合没有 Docker 的 Linux、macOS、Windows 主机、树莓派或老旧小主机：

#### 1. Linux / macOS
```bash
# 赋予执行权限并直接启动（脚本会自动创建 Python 虚拟环境并安装依赖）
chmod +x start.sh
./start.sh
```

#### 2. Windows
直接双击运行仓库根目录下的 **`run.bat`** 即可。

> 💡 **宿主机运行优势**：可直接透传真实局域网 IP（如 `192.168.1.x`），便于后台审计与管理。可选安装 `ffmpeg` 以支持视频缩略图生成。

## 📁 目录结构与数据持久化

容器会将数据持久化在挂载的 `./data` 目录下：

```
data/
├── chat.db          # SQLite 数据库（用户信息、消息、文件索引）
├── uploads/         # 用户上传的文件存储
├── quick_drop/      # 快捷投递目录（直接扔进该目录的文件自动在网盘展示，不写库）
├── previews/        # 视频/图片自动生成的缩略图
├── avatars/         # 用户自定义头像
└── tmp_uploads/     # 大文件分片上传临时缓存
```

## 🛠️ 技术栈

- **后端**：Python 3.11, FastAPI, Uvicorn, SQLite3, ffmpeg
