# LAN Chat 局域网聊天室

**中文说明文档** | [English](README_EN.md)

> **作者**: [@EI3247](https://github.com/EI3247)
> **开源地址**: [https://github.com/EI3247/lan-chat](https://github.com/EI3247/lan-chat)
> **开源协议**: [MIT License](LICENSE)

一个跑在局域网里的聊天室兼文件共享服务。单个容器就能跑起来，不依赖任何第三方服务，数据全部留在自己的机器上。适合家庭 NAS、小型团队、实验室这类不方便把内部通信放到公网上的场景。

技术上由 FastAPI + SQLite + 原生 JavaScript 构成：后端一个 `main.py` 文件，前端无构建步骤，改起来不需要前端工具链。消息走 WebSocket 实时推送，大文件传输走 WebRTC 点对点通道。

---

## 功能说明

### 身份与登录

进入聊天室只需要一个昵称和一个头像，没有注册流程。首次进入时系统分配一个 6 位身份码。

这个身份码就是账号凭证：

- 在设置页可以把身份码改成自定义的字符串，支持中文。
- 可以选择给身份码再加一层个人密码。
- 换设备、换浏览器或者清了缓存之后，输入「身份码 + 密码」即可找回原来的身份，头像、私人消息、个人文件都跟着回来。
- 如果在新设备上已经发过一些消息才恢复身份，这些消息会自动并入原账号，不会丢。

### 聊天消息

- 群聊基于 WebSocket 实时推送，支持文字、图片、视频、音频和其他任意类型文件。
- 支持私聊：消息只有收发双方可见，在聊天流里以不同底色区分。
- 发出去的消息可以编辑、撤回、再恢复；撤回的消息管理员还能从后台还原。
- 公开/私人状态可以随时切换，切换后消息按重新发送处理，时间更新到当前。
- 长文本消息自动折叠，点开查看全文。
- 点击头像打开用户名片，可以看到对方的资料和最近发言，并从这里发起直传或私聊。

### 文件与网盘

`/files` 是独立的网盘页，和聊天流共用一套存储：

- 公开模式看所有人共享的文件，私人模式只看自己的。
- 「我的上传」筛选项可以快速过滤出当前账号上传过的全部文件。
- 自己上传的文件可以在网盘页直接撤回，或在公开/私人之间切换。
- 图片和视频自动生成缩略图，列表是瀑布流布局，移动端两列，宽屏最多五列。
- 纯文本文件支持在线查看；自己上传的还可以在线编辑保存。
- 上传大文件时分片进行，页面刷新不丢进度。

### Quick Drop 快捷投递

这是给 NAS 用户准备的一个口子：把任意文件直接放进宿主机的 `data/quick_drop/` 目录，刷新网盘页就能看到，不用经过上传流程，也不写数据库。文件以「快捷分享」标注显示，只能下载，不能撤回。目录实时扫描，没有定时任务。

### WebRTC 点对点直传

两台设备之间传大文件时，可以不走服务器中转：

- 在对方名片里点「直传文件」，对方确认后建立 WebRTC 数据通道，文件直接从发送方设备写到接收方设备。
- 不占服务器磁盘空间，也不消耗服务器的上行带宽。
- 一次可以选多个文件，接收方确认一次，之后按队列依次传完，全程复用同一条连接。
- 单个文件最大 5GB，64KB 分片传输，带流量控制和实时进度。
- 等待接受和传输过程中都可以取消。
- 发起前会检查对方是否在线，离线用户不能发起。

需要说明的限制：这套直传没有配置 STUN/TURN 服务器，只在同一局域网内可用。跨公网（比如通过 frp 穿透）时信令能通但数据通道建立不起来，文件会退回到普通上传路径。

### 管理后台

后台入口刻意做得很隐蔽：界面上没有任何管理按钮，管理员在聊天输入框里直接输入超级密码并发送，验证通过就跳转到 `/admin`。

后台能做的事：

- 用户管理：查看全部用户（昵称、身份码、来源 IP、活跃时间），支持搜索和分页。
- 消息管理：全量检索、编辑、删除、恢复撤回的消息。
- 文件管理：浏览所有上传文件、预览、下载、删除。
- 配置项：修改站点标题、欢迎语、访问密码、超级密码、上传大小限制（设为 0 表示不限制）。
- 版本页：显示运行版本、主机信息、Python 版本等运行时数据。

密码机制有两层：访问密码管进聊天室，超级密码管进后台。两者都可以在后台修改，改超级密码时会同时更新表单登录和暗号跳转两条验证路径。

### 兼容性

桌面浏览器和移动端浏览器都适配，界面响应式布局。针对内核较旧的轻量 WebView（比如安卓上的 X 浏览器、各类 App 内嵌浏览器）做了专门的兜底：`<dialog>` 元素有降级方案，ES2020 语法的可选链操作符已全部替换为兼容写法，WebSocket 在不携带 cookie 的 WebView 里通过 token 参数认证。这类环境下的聊天和文件收发都能正常工作。

## 常见操作

| 想做什么 | 怎么做 |
|---|---|
| 找回账号 | 登录页输入原来的身份码（+ 密码） |
| 把文件给别人 | 对方在线时用名片页的「直传文件」；离线时直接发到群里 |
| 给 NAS 里已有的文件建索引 | 复制进 `data/quick_drop/` 目录 |
| 进入管理后台 | 在聊天框输入超级密码发送 |
| 限制别人传大文件 | 后台配置里设置上传大小限制 |

## 已知限制

如实列一下这个项目不做的事：

- P2P 直传仅限局域网，跨公网不可用（原因见上文）。
- Docker bridge 网络下，后台看到的客户端 IP 是网桥地址，不是设备真实 IP。需要真实 IP 审计的话用下面的宿主机原生方式部署。
- 没有做消息端到端加密，内网明文传输，别把它暴露到公网上。
- SQLite 单文件数据库适合几十人以下规模，更大的并发没有测过。

## 🚀 快速启动与部署方式

本项目提供两种部署方式：**Docker 容器部署（推荐）** 与 **宿主机原生直接运行（免 Docker）**。

### 方式一：使用 Docker Compose（推荐，容器隔离）

```bash
docker compose up -d
```
默认配置下服务将运行在 `http://你的局域网IP:1111`。

#### `docker-compose.yml` 配置说明
```yaml
services:
  lan-chat:
    build: ./app
    container_name: lan-chat
    restart: unless-stopped
    ports:
      - "1111:1111"
    command: ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "1111", "--proxy-headers", "--forwarded-allow-ips", "*"]
    environment:
      # 访问密码：首次进入聊天室时使用（留空则免密）
      LANCHAT_ACCESS_PASSWORD: "change_this_access_password"
      # 后台管理密码：访问 /admin 时使用（留空则免密）
      LANCHAT_ADMIN_PASSWORD: "change_this_admin_password"
      # 会话签名密钥（生产环境建议修改为随机字符串）
      LANCHAT_SECRET_KEY: "change-this-secret-lan-chat-key"
      LANCHAT_DATA_DIR: "/data"
      LANCHAT_SITE_TITLE: "LAN Chat"
      LANCHAT_WELCOME: "局域网聊天室"
    volumes:
      - ./data:/data
```

---

### 方式二：宿主机原生运行（免 Docker，支持真实局域网 IP 审计）

适合没有 Docker 的 Linux、macOS、Windows 主机、树莓派或老旧小主机：

#### 1. Linux / macOS
```bash
# 赋予执行权限并直接启动（脚本会自动创建 Python 虚拟环境并安装依赖）
chmod +x start.sh
./start.sh
```

#### 2. Windows
直接双击运行仓库根目录下的 **`run.bat`** 即可。

> 💡 **宿主机运行优势**：可直接透传真实局域网 IP（如 `192.168.1.x`），便于后台审计与管理。可选安装 `ffmpeg` 以支持视频缩略图生成。

## 📁 目录结构与数据持久化

容器会将数据持久化在挂载的 `./data` 目录下：

```
data/
├── chat.db          # SQLite 数据库（用户信息、消息、文件索引）
├── uploads/         # 用户上传的文件存储
├── quick_drop/      # 快捷投递目录（直接扔进该目录的文件自动在网盘展示，不写库）
├── previews/        # 视频/图片自动生成的缩略图
├── avatars/         # 用户自定义头像
└── tmp_uploads/     # 大文件分片上传临时缓存
```

## 🛠️ 技术栈

- **后端**：Python 3.11, FastAPI, Uvicorn, SQLite3, ffmpeg
- **前端**：原生 HTML5 / CSS3 / JavaScript (无额外 Node.js 构建链，轻量高效)
- **协议通信**：WebSocket (Hub 连接池) + WebRTC (RTCDataChannel)
